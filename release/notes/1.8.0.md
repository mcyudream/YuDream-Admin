# 版本 1.8.0

- 【minor】知识库级联删除与编辑器文档一键收录、公开侧栏原文档优先
  - 删除原文档的级联清理补全：生成页面唯一来源是被删除资料时一并删除（特殊页与原文档页保留），不再残留失去出处的孤立页
  - 资料库新增「勾选收录编辑器文档」：把编辑器文档的当前正文一键收录为原始资料并进入摄入管道，文档本身不动
  - 公开阅读侧栏调序：原文档区提前优先展示，LLM 生成组收在其后
- 【patch】知识库索引清理降级——图数据库不可达不再阻断删除
  - 删除页面/知识库、取消发布时同步清理 Neo4j 图谱索引，图库不可达（如未部署 Neo4j）会以 ServiceUnavailableException 阻断删除并回滚主数据
  - 现改为降级语义：索引清理失败记录告警并继续删除/取消发布，残留索引由既有「重建索引」清空兜底
