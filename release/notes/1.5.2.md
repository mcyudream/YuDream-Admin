- 【patch】测试夹具归位与遗留文件清理
  - 根目录 tests/ 契约夹具并入 bootstrap 测试资源，双端引用与既有类型错误一并修正
  - 移除 Temp 走查快照与根目录设计预览等遗留文件，补齐忽略规则
- 【patch】仓库历史垃圾清理
  - 从全部历史移除 tmp/（含 257MB 运行时 jar 与日志）、.pixso-replica/、.idea/、散落日志与 install.cmd/served-shop7.js 误提交文件
  - 补齐 .gitignore 整段忽略规则防止复发；发布 tag 迁移到重写后等价提交，历史对象经 bundle 与 commit-map 保留审计
- 【patch】插件运行时软依赖接线与上传覆盖级联恢复
  - dependencyClassLoaders 软依赖分支从「已启用」放宽为「已加载」，热重载/级联恢复窗口内消费方不再永久缺失提供方 API 类（修复 minecraft-server 恢复时端点注册抛 NoClassDefFoundError）
  - dev 插件重载增加启用防御：enable 被跳过时恢复依赖方前重试 enableOwnRuntime 并告警
  - 手动上传覆盖已安装插件改走市场更新级联链路：受控停机目标与依赖方、备份替换后按依赖顺序自动恢复，不再要求先手动卸载/停用
- 【patch】站点导航删除失效修复与知识库子菜单自动对齐
  - 修复站点导航编辑器 structuredClone 作用于响应式代理抛 DataCloneError 导致删除/改名/移动静默失败的问题
  - 导航条目支持 visible=false 显式隐藏：不渲染但地址参与去重，可压制插件页面/插件市场/知识库/首页等 appendAuto 自动追加条目；编辑器删除这类地址时引导改为隐藏
  - 知识库导航条目支持 autoChildren：子菜单自动同步公开知识空间，手动子菜单优先、按地址去重；mc-terrain-theme 预设同步迁移
  - TS/Java 双端校验器放行 visible/autoChildren 布尔字段，共享契约夹具补有效与无效用例
