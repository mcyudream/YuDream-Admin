# 版本 1.6.0

- 【minor】平台能力门控收敛为内部双闸门
  - 废除部署侧 PLATFORM_*_ENABLED 环境变量门控，能力配置改为内部字面量默认开启，启停统一经管理后台能力管理页（项目配置闸门 + 应用闸门）
  - docker-compose 与 .env.example 同步移除对应变量；存量部署如依赖环境变量关能力，升级后需改在能力管理页操作
- 【minor】站点数据驱动反馈设计器与 CMS 端数据模型编辑
  - 设计画布「预览」按公开站同一数据管线解析真实数据（数据源展开、内容值与计数填充，无数据保留作者示例），展开结果不回流文档，退出即恢复可编辑内容
  - 修复预览切换失效：部分 grapes 版本 run/stop:core:preview 事件不触发，改以 isActive 回读驱动
  - 「站点内容」页新增数据模型编辑：分区与字段结构化增删改/排序/默认值/下拉选项/列表条目字段，保留已填值、字段改键携带旧值
- 【minor】mc-interop v1 well-known 聚合出口
  - 新增 /.well-known/mc-interop-v1.json 根级端点：按协议互采合并 peers 友站清单，聚合缓存 5 分钟并支持 ETag/304 条件请求
  - 互采合并下沉 mc-interop 插件出口完成，宿主纯透传合并结果，消除双层合并的重复拉取
- 【minor】开放注册总开关
  - 安全策略新增 registrationEnabled（默认开放，存量文档升级不误关注册），注册链路宿主级硬校验先于插件拦截器
  - 管理端安全策略页新增开关卡片；关闭后登录页/第三方绑定流隐藏注册入口，绑定仅可登录已有账号
- 【minor】关联实体卡下沉共享包并开放插件实体类型注册
  - components 1.11.1 新增 related-entity 注册表与 YdRelatedEntity 调度组件，plugin-sdk 1.15.1 开放 relatedEntity.register（插件作用域、不能遮蔽宿主内置类型）
  - 宿主内置 user/dept/role 改为宿主属主注册，8 个视图页切 YdRelatedEntity，插件引用归零时按插件码兜底注销实体类型
  - ui-guidelines §7 补登记 YdRelatedEntity 后按失败重发纪律重发契约版本
- 【minor】Word 模板嵌图与契约升版（SPI 2.38.0）
  - SPI system/document 新增 PluginWordTemplateImage（格式白名单与可选宽度），契约按纪律 2.37.0 升 2.38.0
  - Word 模板渲染器支持占位符嵌图：独立段落与行循环内生效，高度按比例、超宽收缩到 6 英寸内；图片值出现在文本上下文时降级为「[图片]」文字
- 【patch】公开站接管与前端稳定性修复
  - 公开站外壳、Shadow DOM 页面与草稿预览桥接管 /profile、/logout 账号菜单链接：个人资料弹窗与登出行为与宿主 chrome 一致，不再落「找不到页面」
  - 修复路由页模板根为 fragment 时 out-in 过渡永久卡死导致全站导航白屏的问题（插件发布/发布审核页面即此因）
  - GIF 文件不再生成 JPEG 缩略图，透明与动图封面原样回退
