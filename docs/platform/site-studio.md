# 网站工作台

> **适用范围**：CMS 结构化站点设计、主题微调、媒体管理与发布。
> **目标**：在一个入口完成编辑与发布，同时保留旧 CMS 的兼容路径。

## 1. 入口与内容归属

“网站工作台”是新的 CMS 入口。历史菜单路径保持兼容；旧主题中心与文件工作区保留为旧版入口，不自动迁移或覆盖已有内容。

每个主题有独立的站点草稿和发布指针。编辑目标主题不等于激活该主题：公开 `/site` 始终读取当前激活 SITE 主题的发布文档。没有新版发布文档时，继续使用旧 CMS 或插件原生主题。

## 2. 草稿和线上版本分离

- 编辑、导入和 AI 修改只改变本地草稿。
- 保存草稿不会更新线上站点。
- 发布先校验文档，再原子保存快照并切换发布指针。
- 恢复历史版本仅恢复到草稿，需要再次发布才上线。
- 停止新版发布只清除发布指针，保留草稿和历史，公开站回退旧系统。
- 保存、发布、停止发布与恢复均携带字符串 `expectedRevision`。冲突拒绝，不自动覆盖他人的更改。

每份文档最多 2 MiB、6000 个节点（整站合计）、32 层、200 个页面和 500 个资源。历史最多保留 20 个发布快照；草稿与快照的 UTF-8 内容总预算为 10 MiB，达到预算时淘汰最旧的非线上快照，当前线上版本保留。此历史是有界回滚能力，不是无限备份。

## 3. 编辑源与生成页面

`schemaVersion=1` 的站点文档包含页面节点树、主题变量、页头、页脚与资源清单。节点具有稳定 ID；HTML/CSS 是临时渲染投影，不作为第二份可独立覆盖的权威源。

页面、图层、属性与 AI 修改都使用统一命令。批处理全部成功才生效，失败不污染原文档。撤销重做属于编辑会话，不是服务器端的永久操作日志。

当前安全文档支持语义展示元素和图片、视频、音频等资源，不执行导入的脚本、事件属性或任意 Vue 源码。同一 schemaVersion 采用精确字段校验；未知格式需显式迁移，不静默执行。

### 3.1 主题样式（schemaVersion 1 的可选扩展）

- `theme.classes`：共享样式类。节点经 `class` 属性引用；编译为文档作用域内的 `.名称` 规则，先于节点规则输出（节点自身样式同特异度后写覆盖）。状态 `hover / focus / active / current / pressed` 分别编译为 `:hover`、`:focus-visible`、`:active`、`[aria-current="page"]`、`[aria-pressed="true"]`；父级状态 `parent-hover / parent-focus / parent-expanded` 编译为 `:hover>.名称`、`:focus-within>.名称`、`[aria-expanded="true"]>.名称`，用于无脚本展开二级菜单（样式表写法 `:hover > .名称 {}`）；断点同节点（992/768）。类名 `[a-z][a-z0-9-]{0,63}`，最多 500 个。
- `theme.fonts`：引用 `kind=font` 资产的 `@font-face`（族名限字母数字空格下划线连字符，最多 32 个）。
- `theme.keyframes`：关键帧动画，帧键 `from/to/0%–100%`，帧内声明与节点样式同一校验，最多 64 个。
- 工作台「主题 → 主题样式表」以受限 CSS 文本编辑以上三项（只接受能无损映射的写法），「高级：完整主题 JSON」同样可编辑。编辑画布把主题级 CSS 以独立 `<style>` 注入，不进入引擎 CSS，因此不会回流为逐节点样式。
- 旧主机（未含本扩展）会拒绝带这些字段的文档；TS 与 Java 两端校验同步，共享契约 fixture 覆盖有效与无效用例。

### 3.2 站点功能与数据（宿主运行时，非脚本）

公开站与草稿预览的 iframe 仍禁止脚本；以下行为由宿主在同源文档上实现，文档只声明意图：

- `features.audio`：背景音乐曲目（音频资产，按序循环）、音乐/音效音量、默认是否开启音效、链接/按钮/进入提示音效。访客经 `data-yd-action="toggle-music|toggle-sound"` 按钮开关，状态写入 `aria-pressed`；音乐状态在宿主侧，切换页面不中断，离开站点停止。浏览器不允许无操作自动播放。
- `features.particles` 与页面 `settings.particles`：氛围粒子预设（dust/snow/petals/spores/embers/stars），系统“减少动态效果”时关闭。
- 页面 `settings.iconAssetId`：页面图标，站点导航数据中指向该页的条目带上 `icon`。
- `features.navigation`：站点导航（最多两级、每级 30 项，名称/地址/图标），随草稿发布；数据源 `site:navigation` 以它为准，`appendAuto` 时按 URL 去重追加插件 siteNav 页面与插件市场/知识库入口。未设置时回落「主题中心 → 导航」与站点页面。工作台「主题 → 站点导航」编辑。
- `features.dataSources`（插件数据适配器）：把插件匿名公开接口 `/api/plugins/{插件}/public/...`（仅 GET、不带凭据；校验禁止其他前缀、`..` 与外部地址）声明为数据源 `adapter:{编码}`；路径 `{参数}` 取页面地址查询参数，`single` 表示单条（详情），`recordsPath` 指向列表，`fields` 做字段改名。用于插件主题块之外的数据与详情页（列表条目以链接模板 `data-yd-link="/site/activity?id={id}"` 跳转；同一页面只换查询参数时重载框架文档按新参数取数）。工作台「主题 → 插件数据适配器」可试取接口查看字段。
- `features.publicSkin`（公开页适配）：登录/注册、知识库、插件市场、插件公开页沿用站点外观。颜色限 `#rrggbb`，宿主换算为站点变量 `--yb-site-*`、组件库中性变量 `--color-*` 与 OKLCH 设计令牌，只在公开路由注入（后台不受影响）；组件库编号主色 `--primary-N` 受品牌令牌门禁约束不覆写。字体须为主题字体族（主题字体以 `@font-face` 注册到文档，Shadow DOM 内依赖它）。`chrome` 为 true 时所有公开页使用站点页头/页脚作为持久外壳，`bottomOffset` 为固定底栏留白；`pixel` 为 true 时嵌入主题页的宿主页面统一直角、硬边框、斜面与投影（按卡片/按钮/输入框等通用选择器，不写插件专属类名）。
- 页面 `settings.hostRoutes`（承载宿主公开页）：访问 `/wiki`、`/market`、插件公开页（如 `/timeline`）或 `/login` 等路由时（最长前缀匹配，需开启站点外壳），宿主页面嵌入该站点页面渲染：整页（背景、页头页脚、物品栏）在 Shadow DOM 中，`data-yd-outlet` 节点内放 `<slot>`，宿主 Vue 页面作为插槽内容投影进来，与菜单页同属一个主题；`data-yd-host-hide` 节点在承载时隐藏、普通访问时 outlet 隐藏；`data-yd-site="pageTitle"` 显示宿主页面标题。嵌入时宿主页面根背景透明。
- 页面 `settings.toast`：首次进入该页时的提示（同一会话每页一次），元素类名 `yd-site-toast-layer / yd-site-toast / -icon / -copy / -title / -body / --out`，主题可定义同名样式类覆盖默认外观。
- 当前页链接自动带 `aria-current="page"`，配合样式类 `current` 状态做导航高亮。
- 账号：`data-yd-auth="guest|user"` 按登录状态显隐，`data-yd-account="name|avatar|initial"` 显示账号名、头像（无头像时首字）；账号菜单链接（控制台 `/`、个人资料 `/profile`、退出 `/logout`）用 `data-yd-host-link` 指向宿主路由。
- 经验条与格式化：`data-yd-progress="scroll"` 宽度跟随页面滚动、`="visited"` 显示本次访问去过的页面数；`data-yd-format="datetime|date|time"` 把时间戳/ISO 时间格式化为本地时间。
- 计数与显隐：`data-yd-count="数据源"` 显示真实条数（首页统计等）；条目内 `data-yd-show / data-yd-hide="字段"` 按字段真假显隐（如服务器在线信号）。数据源另有 `market:categories`（插件市场分类与数量）；市场 v2 协议为裸 JSON，运行时以原生 fetch 读取。
- 菜单：`[data-yd-menu]` 内 `[data-yd-menu-trigger]` 在按钮或触屏上切换 `aria-expanded`（子菜单为 `[data-yd-submenu]` 或嵌套列表），点外部/Esc 收起；桌面悬停由 `parent-hover` 直接展开、链接照常跳转（子菜单贴合触发项并以透明下边框作为悬停桥，指针移入途中不丢失悬停）。当前页落在某菜单的子菜单内时，该菜单触发项也标记为当前。
- 站点信息：`data-yd-site="name|description|logo|copyright|year"` 取宿主「系统设置」的公开站点信息（Logo 写入图片 `src`），未设置时保留作者内容。
- 数据绑定：容器 `data-yd-source`（`site:navigation`、`block:<主题块编码>`、`cms:latest`、`wiki:spaces`、`market:plugins`）与 `data-yd-limit`；容器内首个 `data-yd-item` 为条目模板，其余同标记项是示例；字段经 `data-yd-text / -href / -src / -title` 绑定（链接、图片地址按文档 URL 规则过滤；`$index` 为序号；图片无值时保留作者默认图），条目内 `data-yd-each="children"` 为嵌套列表（如二级菜单，无子项时隐藏并标记 `data-yd-has-children`），`data-yd-link` 为由字段拼出的链接模板。无数据或接口未启用时原样显示作者写的示例条目；`data-yd-sample` 仅在示例状态可见、`data-yd-live` 仅在真实数据时可见，容器外的标记用 `data-yd-for="数据源"` 关联。`site:navigation` 与公开站导航同一合并规则（CMS 导航 + 站点文档页面 + 插件 siteNav 页面 + 插件市场/知识库），其链接与绑定条目链接指向宿主路由（`data-yd-host-link`），不映射到 `/site` 前缀。检查器按手风琴分区（内容、布局、样式类、站点信息与计数、账号与菜单、宿主页面承载、数据绑定、属性、样式）可视化编辑以上属性，同一时间只展开一个分区并记住上次分区；工作台自带 AI 面板，全局 AI 悬浮球在工作台内让位。
- 公开站统一渲染：站点页面与承载的宿主公开页都以 Shadow DOM 渲染到主文档（`StudioShadowLayout`，同一视口滚动、同一入场过渡），文档内 `position: fixed`（背景层、底栏）按访客视口生效；文档经 schema 校验不含脚本、事件属性与危险 URL/CSS。开启站点外壳时页头/页脚由应用级持久外壳渲染（`App.vue`），跨路由不重建，只更新当前链接、账号、经验条，导航位置与数据在所有公开页一致。草稿预览仍用 iframe 以模拟桌面/平板/手机宽度。
- 动态页面：页面路径段可写 `:参数`（如 `/activities/:id`），精确路径优先匹配，参数值与查询参数一起传给数据绑定（插件数据适配器 `{id}`、链接模板 `/site/activities/{id}`）。
- 页面与导航依赖 `requires`（`plugin:插件编码`、`capability:wiki`、`capability:plugin-market`）：任一未启用时页面不注册（匹配时排除，访问落到未找到页），导航条目（含指向该页的条目）隐藏；启用状态取公开前端清单与知识库/市场公开能力。站点主题只承载数据与外观：业务页（如活动列表/详情）由插件以 siteNav 公开路由注册，CMS 页面经 `hostRoutes` 包裹，不在主题里复制业务数据。带 `:param` 的插件路由不进入导航。
- 主题变量可承载图片（`--bg-xxx: url(...)`），主题面板对这类变量直接提供图片资产选择，用于“默认内置、可替换”的背景。

## 4. AI 修改的边界

站点助手继续使用统一聊天与 AiRun 网关，专用 profile 为 `cms-studio`：

- `cms.studio.read` 分页读取真实文档与节点。
- `cms.studio.apply` 原子应用结构化命令。
- `cms.studio.validate` 校验当前真实文档。

设计助手是 CMS 专用面板（不复用通用 Agent 工作台）：顶部显示作用目标（选中元素或整页，可一键改为整页），按目标给出快捷操作；**AI 的每次修改先以变更清单预览**（改写文本前后对照、样式增删、插入/删除/移动的目标），用户点“应用到草稿”才写入，拒绝时把原因返回给模型；等待确认期间草稿被手工修改、请求超时或面板关闭，提议一律作废、草稿不变。应用后仍是一次撤销。

工具绑定可信运行归属、文档、页面、上下文和本地修订。用户修改文档或切换上下文后，陈旧命令拒绝执行。AI 不代用户保存或发布，也不能访问宿主文件系统和 shell。关闭面板只移除前端执行器，不等于取消后台任务。

## 5. 包与资源

主题包和站点包使用有版本的 JSON 容器及资源清单。主题包仅导出设计变量、页头页脚、样式类/字体/关键帧、站点功能及它们引用的资源（导入时资产 id 重排并同步改写字体与音频引用），使用空预览页满足文档结构，不携带站点页面正文；已有 v1 全文档主题包仍可导入。嵌入资源使用明确白名单的 base64 媒体；外部 URL 资源标记为引用，不自动下载，不携带凭据。

因此，含外部引用的包不等于完整离线归档。迁移站点前，应检查这些 URL 在目标站点是否仍可访问。静态 HTML 导出保留页面展示，不会自动附带登录、插件查询或其他服务器端业务。

有声自动播放受浏览器策略限制；应使用用户点击触发或静音播放，而不是依赖强制自动播放。

### 预览与渲染一致性

- 编辑画布、公开站 `/site`、草稿预览与静态导出使用同一份基础样式 `STUDIO_BASE_CSS`（系统字体栈、行高、盒模型；正文与背景色取主题变量 `--foreground`/`--background`），整页 HTML 由 `buildStudioSiteHtml` 统一生成。画布经引擎 `canvas.styles` 注入基础样式，不进入引擎 CSS，也不回流文档。
- 编辑页面时画布连同主题页头页脚一起显示，页头页脚只读（在“页头/页脚”区域中编辑），画布即所见的整页效果。
- 画布 CSS 改用 postcss 按原文解析：引擎默认 CSSOM 解析会展开简写、丢弃含 `var()` 的简写（如 `background: var(--accent)`）并回写文档，曾导致按钮背景丢失；已因此丢失样式的既有草稿需在样式面板中补回。
- 草稿预览：工作台头部“预览站点”在新标签打开 `/site-preview/{主题}/{页面路径}`，与公开站同一渲染容器，可切换页面与桌面/平板/手机宽度。工作台打开时经同源 BroadcastChannel 实时显示内存文档（含未保存更改），否则显示服务端已保存草稿；需登录与 `platform:cms:view`，`cms` 能力关闭时为 404，不对匿名访客开放。

## 6. 编辑效率与旧内容迁移

- 画布提供缩放、适配宽度、预览模式、选中面包屑与图层双向选择。撤销、重做、复制及删除快捷键经统一命令执行，输入框、弹窗、内联编辑和无编辑权限时不截获。
- 区块插入器参照 WordPress：搜索（标题前缀优先，匹配关键词）、最近使用（按账号保存在本机）与文本/媒体/设计/布局/小组件/我的模板分类。默认插在选中元素之后，可切换插入到可含子节点的选中容器内部，无选中时追加到当前页面或页头页脚末尾；多节点区块一次撤销。
- 区块来自统一注册表：宿主核心区块、用户区块模板与（规划中的）插件区块共用同一入口，每次插入生成全新节点与 ID，并按站点文档规则校验，来源不可信时拒绝插入。
- 用户区块模板保存在服务端、站点内共享（`/api/platform/cms/block-templates`，权限 `platform:cms:block-template:view/create/edit/delete`）：选中元素后“保存选中”，可设分类、说明与关键词，并出现在区块搜索与“我的模板”分类中。模板是独立副本，不是联动组件；内容上限 256 KiB、全站最多 500 个，编辑按版本冲突拒绝。旧版本机片段可一键迁移为模板，本机数据不删除。
- “旧版与迁移”可读取当前主题的旧首页及文章，显式选择并预检后复制为新页面。只新增，不删除旧数据、不自动保存或发布；路径冲突分配新路径，首页默认 `/imported-home`。
- “旧版与迁移 → 网页导入”：选择网站文件夹（HTML + CSS + 资源），把其中一个网页转换为页面，可同时替换页头/页脚。简单类规则映射为同名样式类；其他选择器（后代、属性、id、`body[data-page]` 等）按该网页的实际匹配结果生成样式类挂到节点，按原特异度与源码顺序排列；末尾状态伪类与配置的“当前页类名”（如 `is-active`）转为样式类状态；`max-width` 媒体查询就近映射到两个断点（480px 以下、`min-width` 与偏好查询跳过）；`@keyframes`、`@font-face`、`:root` 变量分别进入关键帧、字体与主题变量；`html/body` 规则只把可继承属性带到区域顶层节点。内联 SVG 栅格化为 PNG。被引用的资源按相对路径上传并复用；伪元素、祖先状态选择器、脚本与表单等跳过并在分析报告中列出。先分析后导入，一次 batch，可撤销、不自动保存。动态网页需先保存渲染后的 HTML。
- 旧首页优先识别 `homeHtml/homeCss`；自定义 JS、仅工程 JSON 或无法解析的内容逐项拒绝。Markdown 支持纯文本或安全渲染迁移。未映射设置和资源外部引用会明确告知，锚点冲突重映射。
- 画布引擎 DOM 与 Vue 加载/错误提示已物理隔离，避免初始化清空 Vue 锚点造成 `insertBefore` 异常。长 CSS 值的函数校验改为顺序扫描，避免长 token 回溯阻塞。

## 7. 当前不承诺的能力

- 第三方代码主题自动安装依赖并执行。
- 完整 Figma 矢量编辑或多人实时协作。
- 任意脚本、伪元素、祖先状态选择器和所有自定义断点的无损导入（网页导入会跳过并报告）。
