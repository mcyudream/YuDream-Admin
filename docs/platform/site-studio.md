# 网站工作台

> **适用范围**：CMS 结构化站点设计、主题微调、媒体管理与发布。
> **目标**：在一个入口完成编辑与发布，同时保留旧 CMS 的兼容路径。

## 1. 入口与内容归属

“网站工作台”是新的 CMS 入口。历史菜单路径保持兼容；旧主题中心与文件工作区保留为旧版入口，不自动迁移或覆盖已有内容。

每个主题有独立的站点草稿和发布指针。编辑目标主题不等于激活该主题：公开 `/site` 始终读取当前激活 SITE 主题的发布文档。没有新版发布文档时，继续使用旧 CMS 或插件原生主题。

## 2. 草稿和线上版本分离

- 编辑、导入和 AI 修改只改变本地草稿。
- 保存草稿不会更新线上站点。
- 发布先校验文档，再原子保存快照并切换发布指针。
- 恢复历史版本仅恢复到草稿，需要再次发布才上线。
- 停止新版发布只清除发布指针，保留草稿和历史，公开站回退旧系统。
- 保存、发布、停止发布与恢复均携带字符串 `expectedRevision`。冲突拒绝，不自动覆盖他人的更改。

每份文档最多 2 MiB、2000 个节点、32 层、200 个页面和 500 个资源。历史最多保留 20 个发布快照；草稿与快照的 UTF-8 内容总预算为 10 MiB，达到预算时淘汰最旧的非线上快照，当前线上版本保留。此历史是有界回滚能力，不是无限备份。

## 3. 编辑源与生成页面

`schemaVersion=1` 的站点文档包含页面节点树、主题变量、页头、页脚与资源清单。节点具有稳定 ID；HTML/CSS 是临时渲染投影，不作为第二份可独立覆盖的权威源。

页面、图层、属性与 AI 修改都使用统一命令。批处理全部成功才生效，失败不污染原文档。撤销重做属于编辑会话，不是服务器端的永久操作日志。

当前安全文档支持语义展示元素和图片、视频、音频等资源，不执行导入的脚本、事件属性或任意 Vue 源码。同一 schemaVersion 采用精确字段校验；未知格式需显式迁移，不静默执行。

## 4. AI 修改的边界

站点助手继续使用统一聊天与 AiRun 网关，专用 profile 为 `cms-studio`：

- `cms.studio.read` 分页读取真实文档与节点。
- `cms.studio.apply` 原子应用结构化命令。
- `cms.studio.validate` 校验当前真实文档。

设计助手是 CMS 专用面板（不复用通用 Agent 工作台）：顶部显示作用目标（选中元素或整页，可一键改为整页），按目标给出快捷操作；**AI 的每次修改先以变更清单预览**（改写文本前后对照、样式增删、插入/删除/移动的目标），用户点“应用到草稿”才写入，拒绝时把原因返回给模型；等待确认期间草稿被手工修改、请求超时或面板关闭，提议一律作废、草稿不变。应用后仍是一次撤销。

工具绑定可信运行归属、文档、页面、上下文和本地修订。用户修改文档或切换上下文后，陈旧命令拒绝执行。AI 不代用户保存或发布，也不能访问宿主文件系统和 shell。关闭面板只移除前端执行器，不等于取消后台任务。

## 5. 包与资源

主题包和站点包使用有版本的 JSON 容器及资源清单。主题包仅导出设计变量、页头页脚及它们引用的资源，使用空预览页满足文档结构，不携带站点页面正文；已有 v1 全文档主题包仍可导入。嵌入资源使用明确白名单的 base64 媒体；外部 URL 资源标记为引用，不自动下载，不携带凭据。

因此，含外部引用的包不等于完整离线归档。迁移站点前，应检查这些 URL 在目标站点是否仍可访问。静态 HTML 导出保留页面展示，不会自动附带登录、插件查询或其他服务器端业务。

有声自动播放受浏览器策略限制；应使用用户点击触发或静音播放，而不是依赖强制自动播放。

### 预览与渲染一致性

- 编辑画布、公开站 `/site`、草稿预览与静态导出使用同一份基础样式 `STUDIO_BASE_CSS`（系统字体栈、行高、盒模型；正文与背景色取主题变量 `--foreground`/`--background`），整页 HTML 由 `buildStudioSiteHtml` 统一生成。画布经引擎 `canvas.styles` 注入基础样式，不进入引擎 CSS，也不回流文档。
- 编辑页面时画布连同主题页头页脚一起显示，页头页脚只读（在“页头/页脚”区域中编辑），画布即所见的整页效果。
- 画布 CSS 改用 postcss 按原文解析：引擎默认 CSSOM 解析会展开简写、丢弃含 `var()` 的简写（如 `background: var(--accent)`）并回写文档，曾导致按钮背景丢失；已因此丢失样式的既有草稿需在样式面板中补回。
- 草稿预览：工作台头部“预览站点”在新标签打开 `/site-preview/{主题}/{页面路径}`，与公开站同一渲染容器，可切换页面与桌面/平板/手机宽度。工作台打开时经同源 BroadcastChannel 实时显示内存文档（含未保存更改），否则显示服务端已保存草稿；需登录与 `platform:cms:view`，`cms` 能力关闭时为 404，不对匿名访客开放。

## 6. 编辑效率与旧内容迁移

- 画布提供缩放、适配宽度、预览模式、选中面包屑与图层双向选择。撤销、重做、复制及删除快捷键经统一命令执行，输入框、弹窗、内联编辑和无编辑权限时不截获。
- 区块插入器参照 WordPress：搜索（标题前缀优先，匹配关键词）、最近使用（按账号保存在本机）与文本/媒体/设计/布局/小组件/我的模板分类。默认插在选中元素之后，可切换插入到可含子节点的选中容器内部，无选中时追加到当前页面或页头页脚末尾；多节点区块一次撤销。
- 区块来自统一注册表：宿主核心区块、用户区块模板与（规划中的）插件区块共用同一入口，每次插入生成全新节点与 ID，并按站点文档规则校验，来源不可信时拒绝插入。
- 用户区块模板保存在服务端、站点内共享（`/api/platform/cms/block-templates`，权限 `platform:cms:block-template:view/create/edit/delete`）：选中元素后“保存选中”，可设分类、说明与关键词，并出现在区块搜索与“我的模板”分类中。模板是独立副本，不是联动组件；内容上限 256 KiB、全站最多 500 个，编辑按版本冲突拒绝。旧版本机片段可一键迁移为模板，本机数据不删除。
- “旧版与迁移”可读取当前主题的旧首页及文章，显式选择并预检后复制为新页面。只新增，不删除旧数据、不自动保存或发布；路径冲突分配新路径，首页默认 `/imported-home`。
- 旧首页优先识别 `homeHtml/homeCss`；自定义 JS、仅工程 JSON 或无法解析的内容逐项拒绝。Markdown 支持纯文本或安全渲染迁移。未映射设置和资源外部引用会明确告知，锚点冲突重映射。
- 画布引擎 DOM 与 Vue 加载/错误提示已物理隔离，避免初始化清空 Vue 锚点造成 `insertBefore` 异常。长 CSS 值的函数校验改为顺序扫描，避免长 token 回溯阻塞。

## 7. 当前不承诺的能力

- 任意既有 Vue 代码无损转换为可视化节点。
- 第三方代码主题自动安装依赖并执行。
- 完整 Figma 矢量编辑或多人实时协作。
- 任意脚本、完整伪类/动画 CSS 和所有自定义断点的无损导入。
- 外部资源自动抓取，或将动态后端功能自动变成纯静态网站。

后续代码组件和业务数据绑定需要单独的组件契约、依赖及信任模型，不通过开放任意 HTML/JS 绕过。
