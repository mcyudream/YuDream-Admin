# 工作台画布与卡片

## 布局规则

`views/dashboard/layout.ts` 是布局的唯一模型。`DashboardCanvas.vue` 管理 GridStack 生命周期与指针操作，`views/index.vue` 管理接口、编辑草稿和历史记录。浏览和编辑使用同一份坐标、行高、卡片结构；禁止按编辑状态另算高度或切换内容版式。

画布以自身可用宽度计算网格：1120px 起 12 列、800px 起 8 列、540px 起 4 列，其余单列。每行 100px、网格内边距 8px；四套断点坐标继续兼容现有 dashboard API。页面的移动端工具栏仍使用全站 768px 断点。打开侧栏或改变窗口宽度只切换网格，不销毁和重新挂载卡片。

模型负责边界约束、旧布局碰撞修复、隐藏卡片和不可用插件不占位。已有保存布局保留，首次生成的布局采用推荐算法。推荐排布在桌面将欢迎区与常用入口放在同一行；整理空隙仅调整当前断点，保留尺寸。

## 编辑事务

- 拖动卡片标题移动、右下角缩放；卡片菜单提供尺寸和前后移动操作，可用键盘操作。
- 卡片库支持按名称、描述、分类和插件搜索。隐藏可随时重新添加。
- 拖动、缩放、添加、隐藏、整理、推荐、使用默认布局均进入撤销/重做历史。
- 所有操作先改草稿，点击保存才写 API；取消恢复原始布局。保存失败保留草稿。
- 个人布局和管理员默认布局有独立入口；默认布局入口继续受 `system:dashboard:config` 权限控制。
- 编辑时卡片业务内容设为 inert，避免拖拽过程触发插件业务操作。

GridStack 只初始化一次。异步初始化使用修订号与卸载标志防止过期任务回写；程序化排布不进入用户操作历史。图表和远程卡片在网格完成初始化后挂载，避免初始宽高为零。

## 卡片与主题

欢迎区采用深色主题表面，入口、指标、插件内容各有信息层级。常用入口采用四列图标导航，分类放入悬停提示，避免重复的灰色按钮与说明；小于 260px 的窄卡片降为两列。指标不再在卡片内重复套四个小卡片。所有卡片使用固定 56px 标题区；远程内容通过 flex 高度链撑开，宽高由宿主画布决定。

工作台专用主题默认值放在 `src/assets/styles/dashboard-appearance.css` 的 `yudream-base` 层：

| 变量 | 用途 |
| --- | --- |
| `--yd-dashboard-feature-bg` | 欢迎区表面 |
| `--yd-dashboard-feature-text` / `muted` | 欢迎区主次文字 |
| `--yd-dashboard-info` / `success` / `warning` | 卡片图标语义颜色 |

ADMIN 插件可在根节点覆盖这些变量；无主题插件时使用宿主默认值。圆角、阴影、密度和动效继续使用 `--yd-*` 既有契约。SITE 主题不介入后台画布。卡片入场、入口悬停和按压反馈尊重宿主与系统的减少动态效果设置。

配套插件改进：钱包将明细入口放在主余额旁边、异常配置名称显示资产编码；角色卡片以角色名和两行装备清单呈现，管理入口跟随角色标题；皮肤画布适配卡片尺寸，角色名、装备状态与换装操作收进同一底栏，材质全名放在提示中。皮肤预览推荐 3 行、节点监控推荐 2 行，尺寸由插件声明，宿主不按插件名硬编码。Authlib 地址聚焦复制与拖入操作。手机端宠物默认收起，桌面首次进入工作台同样收起，并记住主动展开/收起的偏好。调试入口折叠到边缘，页面底部预留滚动空间。

卡片按内容而非统一四宫格表达：欢迎区补充真实本周日期；运行统计突出一个主指标并纵排辅助数据；趋势卡显示区间总数、明确的日期范围和可交互的每日统计。趋势卡使用宿主 `components/chart/SystemMetricChart.vue` 封装的 ECharts（按需注册折线、柱形、网格、提示框与 SVG 渲染器），继续使用平台 dataset API。接口调用用折线，新增统计用日柱，能力统计用横向条形；完整分析图仍由数据可视化模块承载。推荐排布把三个趋势摘要放到同一桌面行（4 × 3），不会自动覆盖已有保存尺寸。

`metric-chart-options.ts` 统一零基线、整数刻度、按可用宽度疏排的日期和容器内提示框。全零序列显示真实零位点与解释，缺失值保留断点，禁止补成零、平滑夸大波动或构造假趋势。提示框支持指针与触摸，左右键/Home/End 可查看数据，Esc 关闭；读屏可读取完整数据表。区间总数在上、绘图区居中、当前读数和详情操作在下，避免多行重复文案挤压图形。

图表颜色、文字、表面和字体从宿主/ADMIN 插件的实际 CSS 变量读取；将 `color-mix` / `oklch` 解析为 sRGB 后交给 ECharts，不使用固定品牌色。观察根节点外观变化、主题样式装卸与加载，重设选项而不重建实例。ResizeObserver 跟随卡片缩放，宽高非零后才初始化，卸载时清理实例和观察器。绘制与数据更新动画尊重系统及宿主减少动态效果设置。

MC 面板的节点和实例使用各自真实数量与比例，零总数显示未接入/未部署，不生成假趋势。市场与快速开始通过整行入口承载操作；活动中心使用可切换的日期列表，把活动名称放在状态前；皮肤统计避免嵌套四个灰色容器；YMCL 将复制地址、打开启动器和域概览分清主次。插件来源信息留在编辑卡片库，浏览视图不重复标注“扩展”。

## 参考与验证

手机页头采用单行标题与操作，编辑态才显示拖动提示。图表按卡片宽度自动减少日期刻度，提示框不越出绘图区；保持真实零位和零数据说明。活动入口与切换按钮同排，默认尺寸直接展示三条日程，不使用独立底栏挤占列表。

交互参考 [Grafana 的编辑/保存流程](https://grafana.com/docs/grafana/latest/visualizations/dashboards/build-dashboards/create-dashboard/) 和 [GridStack 的响应式网格](https://gridstackjs.com/demo/)，未复制第三方产品界面。

模型回归测试：`pnpm exec tsx --test apps/core-arco-design-vue/src/views/dashboard/layout.test.ts`。现场回归应包含浏览/编辑几何一致性、推荐与撤销、拖拽与缩放、添加与隐藏、取消、保存后刷新，以及桌面、侧栏展开与手机三种画布宽度。

图表回归测试：`pnpm exec tsx --test apps/core-arco-design-vue/src/components/chart/metric-chart-options.test.ts`，覆盖真实峰值/缺失、全零、主题与减少动态效果、窄卡片刻度、提示框、分类和单点。容器生命周期参考 [ECharts 尺寸文档](https://echarts.apache.org/handbook/en/concepts/chart-size/)。
