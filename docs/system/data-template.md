# 系统资源 Excel 导入导出

> **适用范围**：系统管理中的用户、角色、部门、菜单四个管理页及其 `/api/system/excel/{users,roles,depts,menus}/**` 接口。
> **目标**：让每类资源在自己的管理页面完成模板下载、导出和导入，并支持将导出文件带到另一套 YuDream Admin 系统安全回导；不把导入做成独立业务页面，也不把它误用为全实例备份恢复。

## 1. 入口归属与数据备份边界

| 场景 | 使用位置 | 结果 |
| --- | --- | --- |
| 用户资料、部门与角色归属的批量维护 | 用户管理页 | 用户 Excel |
| 角色与权限配置的批量维护 | 角色管理页 | 角色 Excel |
| 部门树与负责人配置的批量维护 | 部门管理页 | 部门 Excel |
| SYSTEM 菜单、路由和权限配置的批量维护 | 菜单管理页 | 菜单 Excel |
| Mongo 全部业务数据、插件范围、对象文件与加密配置的完整恢复 | [数据备份](backup.md) | YDBA 归档 |

四个入口都只创建或更新当前资源，**不会删除**目标系统中 Excel 未出现的记录。模板不携带密码、登录令牌、API Key、头像/附件、消息身份、扩展资料、审计时间或插件归属数据。需要完整实例迁移时必须使用 YDBA，不能把资源导入当作原子数据库恢复。

## 2. 文件与稳定身份

每个资源各使用一个 `.xlsx` 工作表。当前限制为单文件 20MB、最多 8 个工作表、每表最多 10,000 行；导入拒绝公式单元格、过长文本和非法 Excel 文件。

所有 Snowflake ID 都以**文本单元格**保存，绝不能以数值单元格或 JavaScript `Number` 处理。ID 只用于定位同源记录，**新记录始终由目标系统生成自己的 ID**。

| 资源 | 跨系统稳定身份 | 关联引用 |
| --- | --- | --- |
| 部门 | 完整部门路径 | 上级部门路径、负责人用户名 |
| 角色 | 角色编码 | 所属部门路径 |
| 用户 | 用户名 | 部门路径、默认部门路径、角色编码 |
| 菜单 | 菜单编码 | 上级菜单编码 |

导入遵循“来源 ID 优先、稳定业务身份回退”。当来源 ID 与业务身份命中不同记录时，系统按业务身份更新并报告提示；若无法安全定位目标，则该行失败，绝不覆盖无关数据。

## 3. 覆盖范围与保护字段

| 资源 | 可覆盖字段 | 受保护字段 |
| --- | --- | --- |
| 部门 | 名称、父级、负责人、电话、排序、描述、主色、状态 | ID、系统/根部门类型 |
| 角色 | 名称、所属部门、等级、图标、主色、权限、状态 | ID、角色编码、系统角色类型 |
| 用户 | 昵称、邮箱、手机号、QQ、邮箱状态、启停、部门、角色 | ID、用户名、密码、头像、消息身份、标签、扩展资料 |
| 菜单 | 名称、类型、父级、模块、图标、路径、组件、外链、排序、可见性、权限、状态 | ID、编码、来源、插件归属、插件注册键、运行时状态 |

资源页导入采用**增量语义**：空白的可选字段不会误清空已有值。需要清空字段时，请使用该资源的编辑表单进行明确操作。插件菜单不可被导入覆盖；系统/根部门和系统角色只可作为关联锚点，不会被模板修改。

## 4. 导入依赖与执行顺序

跨资源回导时按以下顺序操作：

1. 在**部门管理**导入部门；部门行可乱序，系统会先写父级，再处理停用状态。
2. 在**角色管理**导入角色；角色的所属部门路径必须已存在。
3. 在**用户管理**导入用户；用户的部门路径和角色编码必须已存在。部门负责人按用户名回填，已存在用户也可作为负责人。
4. 在**菜单管理**导入菜单；菜单行可乱序，系统会先写父级、再按子到父处理停用状态，并重建菜单权限目录。

每个资源导入都会先检查本资源中的重复稳定身份、循环层级及其关联引用。Mongo 当前部署不将此通道承诺为跨集合原子恢复：预检通过后按行执行，单行运行期失败会记录到结果，其他独立行可以继续，并可安全重试。

## 5. 新用户密码初始化

用户 Excel 导出不会包含任何密码。目标系统需要新建用户时：

1. 新用户必须提供未被已验证账号占用的有效邮箱；服务端用随机占位密码创建账号，明文密码不会进入 Excel、接口响应、日志或导入结果；
2. 对启用账号签发一次性初始密码设置链接并提交邮件发送任务；
3. 用户通过 `/reset-password` 设置自己的密码后，链接失效，同时完成该邮箱验证。

导入结果中的“初始化邮件已进入发送队列”只表示本机已提交异步发送任务，**不代表邮件已实际送达**。管理员可通过用户管理的“重发初始密码设置邮件”接口重新签发；无邮箱、已停用或邮箱冲突的账号不会获得初始化链接。

## 6. 权限

| 管理页 | 下载模板与导出 | 导入 |
| --- | --- | --- |
| 用户管理 | `system:user:export` / `system:user:import` | `system:user:import` |
| 角色管理 | `system:role:export` / `system:role:import` | `system:role:import` |
| 部门管理 | `system:dept:export` / `system:dept:import` | `system:dept:import` |
| 菜单管理 | `system:menu:export` / `system:menu:import` | `system:menu:import` |

导出和导入均应按最小权限分配。导出的资源可能包含账号和授权配置，下载、存储和传输时应按敏感运维资料管理。
