# 系统数据模板包

> **适用范围**：系统管理 → 数据模板（`system:template:*`）与 `/api/system/excel/template-package/**`。
> **目标**：用可审查、可重复导入的 Excel 模板在不同 YuDream Admin 系统间迁移部门、角色、用户和菜单的受控配置，不把它误用为全实例备份恢复。

## 1. 与数据备份的边界

| 场景 | 使用方式 |
| --- | --- |
| 部门、角色、用户、菜单的配置复制或批量维护 | 系统数据模板包（本功能） |
| Mongo 全部业务数据、插件范围、对象文件、加密配置的完整恢复 | [数据备份](backup.md) 的 YDBA 归档 |

模板包**不会删除**目标系统中模板未出现的记录，也不携带密码、登录令牌、API Key、头像/附件、消息身份、扩展资料、审计时间或插件归属数据。需要完整实例迁移时，必须使用 YDBA；不能将模板导入当成原子数据库恢复。

## 2. 文件协议

文件为 `.xlsx`，协议名 `yudream-system-template`，当前 `schemaVersion=1`，固定包含以下五个工作表：

| 工作表 | 作用 |
| --- | --- |
| `说明` | 格式名、协议版本与安全边界 |
| `部门` | 部门树、路径、负责人用户名与白名单配置字段 |
| `角色` | 角色编码、所属部门路径、授权与白名单配置字段 |
| `用户` | 账号资料、部门路径、角色编码；不含密码 |
| `菜单` | SYSTEM 菜单编码、树关系、路由与权限配置 |

导入拒绝缺少的工作表、未知格式、未来协议版本、重复稳定身份、公式单元格、过长单元格、循环层级和无法解析的关联。当前限制为单文件 20MB、最多 8 个工作表、每表最多 10,000 行。

所有 Snowflake ID 以**文本单元格**保存，绝不能用数值单元格或 JavaScript `Number` 处理。

## 3. 匹配与覆盖规则

导入遵循“来源 ID 优先、稳定业务身份回退”：来源 ID 只用于查找既有记录，**永远不会作为新记录的目标主键**；新记录由目标系统生成自己的 ID。

| 资源 | 稳定身份 | 可覆盖字段 | 受保护字段 |
| --- | --- | --- | --- |
| 部门 | 完整部门路径 | 名称、父级、负责人、电话、排序、描述、主色、状态 | ID、系统/根部门类型 |
| 角色 | 角色编码 | 名称、所属部门、等级、图标、主色、权限、状态 | ID、角色编码、系统角色类型 |
| 用户 | 用户名 | 昵称、邮箱、手机号、QQ、邮箱状态、启停、部门、角色 | ID、用户名、密码、头像、消息身份、标签、扩展资料 |
| 菜单 | 菜单编码 | 名称、类型、父级、模块、图标、路径、组件、外链、排序、可见性、权限、状态 | ID、编码、来源、插件归属、插件注册键、运行时状态 |

当来源 ID 在目标系统恰好命中同一业务身份时，原记录就地更新。当跨系统雪花 ID 不同或来源 ID 撞到无关记录时，系统退回部门路径、角色编码、用户名或菜单编码查找目标。两种身份均无法一致定位时，该行失败并要求人工核对；系统绝不覆盖无关记录。

从“导出当前数据”得到的系统数据模板包是**完整快照**：白名单中的空文本、空权限、空部门或空角色集合会同步清空目标记录的相应可覆盖字段。各资源管理页的旧单表导入仍采用较保守的增量语义；跨系统复制或需要精确回导时应使用系统数据模板包。

插件菜单不可被模板覆盖，系统部门/根部门和系统角色只作为关联锚点，模板不会修改它们。

## 4. 导入顺序与关联

系统在写入前完成整体预检，然后按以下顺序执行：

1. 创建或更新部门结构；
2. 创建或更新角色并解析所属部门；
3. 创建或更新用户并解析部门、默认部门与角色；
4. 回填部门负责人；
5. 创建或更新 SYSTEM 菜单，并重新同步菜单来源的权限目录。

因此模板中的部门或菜单行可以不按父子顺序排列；导入会先建立依赖顺序。单资源 Excel 导入仍适合简单新增/编辑，但涉及跨资源关系、跨系统复制或重复回导时应使用本模板包。

Mongo 当前部署不将此通道承诺为跨集合原子恢复：完整预检通过后逐行执行，单行运行期失败会记录到结果而其他独立行可继续处理。导入可安全重试，不会删除目标独有记录。

## 5. 新用户密码初始化

模板导出不会包含任何密码。目标系统需要新建用户时：

1. 新建用户必须提供未被已验证账号占用的有效邮箱；服务端用随机占位密码创建账号，明文密码不会进入 Excel、接口响应、日志或导入结果；
2. 对启用账号签发一次性初始密码设置链接并提交邮件发送任务；
3. 用户通过 `/reset-password` 设置自己的密码后，链接失效，同时完成该邮箱验证。

导入结果中的“初始化邮件已进入发送队列”只表示本机已提交异步发送任务，**不代表邮件已实际送达**。管理员可通过用户管理的“重发初始密码设置邮件”接口重新签发；无邮箱、已停用或邮箱冲突的账号不会获得初始化链接。

## 6. 权限

| 权限码 | 含义 |
| --- | --- |
| `system:template:view` | 查看数据模板页 |
| `system:template:export` | 下载空白模板或导出当前系统模板包 |
| `system:template:import` | 上传并执行数据模板包导入 |

导出和导入均应按最小权限分配。模板内容包含账号和授权配置，下载、存储和传输时应按敏感运维资料管理。
