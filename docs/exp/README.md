# 经验库索引

> **适用范围**：主仓开发、验收、发布中已经出现且可复用的故障模式。
> **目标**：记录症状到规避的最短诊断路径；规范已升级为硬规则时，规范正文以 `docs/dev/` 为准。

## 1. 条目格式

每条经验按以下四项组织：

- **现象**：用户或日志中可观察到的症状。
- **根因**：经验证的实际原因，不写猜测。
- **规避**：复现、定位、修复或验证的具体步骤。
- **来源**：修复提交、验证记录或权威规范链接。

经验用于快速定位，不替代规范。根因修复后若形成稳定工程约束，应提炼到 `docs/dev/`，本处保留关键诊断线索或删除过时条目。
