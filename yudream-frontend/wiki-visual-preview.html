🔧 技术细节

CSS 变量统一： 所有颜色、动画、间距均通过 CSS 变量（--color-*, --yd-motion-*）实现，支持深色模式

响应式断点：
• 大屏 (≥1280px)：全信息展示
• 中屏 (768-1024px)：压缩空间名称
• 小屏 (<768px)：竖排布局，全宽按钮

动画性能： 采用 GPU 加速的 transform 和 opacity，禁止 layout 抖动

Bug 修复： 从知识库列表进入编辑区时，现在显式传递 spaceId，避免上下文丢失

📍 如何验证

  1. 启动前端开发服务：pnpm dev
  2. 访问 http://localhost:9003
  3. 进入 Wiki 工作台（需要有知识库数据）
  4. 观察编辑页顶部工具条的分层布局和保存状态动画
  5. 进入管理页，观察渐变背景和按钮悬停动画
