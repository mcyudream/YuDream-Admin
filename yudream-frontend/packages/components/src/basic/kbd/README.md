# FaKbd 键盘按键

用于展示键盘按键或快捷键组合的语义样式，不负责监听或执行快捷键。

## 使用场景

- 在操作说明中展示单个键，例如 <kbd>Esc</kbd>
- 在文本中标示键盘输入，例如「按 <kbd>F</kbd> 搜索」
- 展示组合键，例如 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Del</kbd>
- 展示方向键或平台修饰键符号

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 按键尺寸 |
| `class` | `HTMLAttributes['class']` | - | 自定义 CSS 类 |

## Slots

| 名称 | 说明 |
|------|------|
| `default` | 按键内容（字符、简短文本或图标） |

## 使用说明

- 组合键可将多个 `FaKbd` 放入 `FaKbdGroup`；单个按键之间的 `+` 分隔符按需要由调用方提供。
- 尺寸档位用于适配内容层级；默认 `md` 保持原有尺寸。
- 组件只负责展示，不会监听按键，也不会注册快捷键。
- 按键内容宜简短；超长标签可通过 `class` 自定义尺寸。
- 支持 SVG 图标，图标会自动调整为合适尺寸。
